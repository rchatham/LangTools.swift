Current benchmark values and comparison coverage

This page summarizes the current ratio-gated performance values introduced by PR #32. The ratios compare LangTools hot paths against a Foundation JSONSerialization baseline over the same payload in the same run. Lower is better; 1.0× means equal to the Foundation baseline.

Reproduce or update the numbers

Run ratio gates: Scripts/run-extended-tests.sh --filter PerformanceRatioGateTests

Run reporting benchmarks: Scripts/run-extended-tests.sh --filter BenchmarkTests -v

Record new ceilings after an intentional performance change: RECORD_PERF_RATIOS=1 Scripts/run-extended-tests.sh --filter PerformanceRatioGateTests

Performance values are machine- and toolchain-sensitive. Treat this page as a snapshot, not a universal benchmark claim.
